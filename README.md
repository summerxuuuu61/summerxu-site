# Summer Xu · 徐琦然 — 个人作品网站

一个可持续更新的个人作品网站。采用**深色编辑部式排版**（可一键切换浅色白底）：摄影作品按「国家 → 地区」分类，视频分「混剪 / 剧情剪辑」两类。

参考版式：**首页为项目索引**（每个地区一张封面，恢复分类）——上方国家筛选，下方一张张“项目封面卡”，点击进入该地区的照片画廊；页脚含联系方式、栏目导航和「回到顶部」。

> 每张项目封面默认取该地区第一张照片；若想指定封面，给地区加一个 `cover` 字段（如 `cover: "images/photography/china/beijing/001.jpg"`）即可。

## 地区视觉风格

每个地区页有「版头 + 照片展示」，并按地区应用不同风格。通过地区的 `style` 字段控制（默认 `default`）：

- `film` 日系胶片：暖米色底、暖调胶片感（用于日本），并以**胶片浏览条**（横滚 + 齿孔）展示
- `japanese` 日系：浅暖米白、低对比（备用）
- `solemn` 庄严：深色厚重、高对比（用于北京等）
- `urban` 城市夜色：冷调青灰、氛围感（用于重庆等）

例：`style: "film"`、`layout: "film"`（写在国家或地区对象上，地区优先）。

> **分区不给任何组取名**，只按**场景**简单分组：同一地点/建筑的照片（感知哈希相似）聚在一起，其余单张连排。

> **排版对齐**：采用**密集网格**，竖拍自动跨 2 行、横拍跨 2 列，画面**横竖对齐、不留空块**（缩略图为填格裁切；点开大图是完整原图）。

> **同地点 / 同建筑聚合**：每张照片计算**场景感知哈希**（`data/hashes.js`），在同类型分区内，把**场景相似（同地点/同建筑）**的照片聚成一组（不命名），让“同一事物”连在一起。

> 日本区为**日系胶片**：按类型分组的**电影胶卷条**——白底胶片 + 上下齿孔 + `FUJIFILM 400` 品牌标签 + 横向胶片帧（可横向滑动、点帧放大）；其它区按各自风格 + 类型分组。

> **旋转权限**：「管理」模式下每张照片有「**旋转**」按钮，点一下转 90°，用于把没转正的长幅照片手动转正（记录在浏览器本地）。

> 已修复：清理了约 41 张照片残留的**四周白边**（部分照片是带白边框的导出图，之前只裁了底部信息条）。

## 照片排序

地区画廊采用**清爽的分区排版**：按「日期 → 相关性」分组，每个日期是一组，组内再按相关性分成若干子组；照片列数少（桌面 3 列）、**尺寸较大、留白充足**，靠照片天然的长宽比例自然排列，安静耐看不费眼。

- 排序栏已移除（不再需要手动切换
- 单张只有年份、无具体日期的照片排在最后（“未注名”组）

> **互动**：图片悬停有缩放过渡；「管理」模式下**点击任意照片即设为版头**（有提示）、或点按钮「隐藏」；也可**拖拽**调整顺序。

> **管理模式**：进入「管理」后**布局保持可见**，编辑按钮（版头/隐藏/分区/旋转）在**鼠标悬停到照片上才显示**，不会盖住排版；支持**鼠标拖拽**移动照片（网格与胶片均可）；若之前遗留的版头/隐藏/顺序/分区/旋转导致排版异常，点「**清空该区管理**」即可一键恢复干净排版。

> **分区选项**：点照片上的「分区」按钮会**弹出已有分区列表**，点一下即可加入（不用每次打字）；「＋新建分区」输入名称即建，分区 chip 上的 **✎** 可随时**改名**、**✕** 可删除。

> 缩略图已**更小更方便**（桌面约 7 列），便于逐个拖拽整理。

> 分区标题带线条与编号（杂志式）；没有逐张的自动浮现动画，避免视觉疲劳。

> **版头**：管理模式下点照片或「版头」按钮即可更换版头，会提示并自动记住；「恢复顺序」可回到按时间的智能分组。

## 分区编辑（可自定义分区）

「管理」模式下会出现**分区栏**，分区以**拖拽**方式编辑：

- **＋ 新建分区**：输入名称，创建新分区（该分区会成为拖拽的投放区）
- **直接把照片拖到某个分区**（虚线框）即可移入；拖到其它分区可从原分区移走
- 拖到「未分区（自动）」可放回按日期自动分组
- 没有自建分区时，**把照片拖到另一张照片上** = 手动调整顺序
- **点某张照片上的「分区」按钮 → 输入分区名**：把这张照片直接加入该分区（没有就新建）
- 点「**自动**」chip：把照片移回自动按日期分组
- 分区 chip 上的 **✕**：删除该分区

自定义分区会存档在浏览器本地（localStorage），也可用「导出设置」导出 JSON 让我固化到数据文件（`region.sections`），对所有人生效。

> 地球 v2：改用**真实地形地球贴图**（大陆/海洋 + 光照，显得立体）；地点为**彩色图钉 + 悬停显示地名**；支持**拖拽旋转、滚轮缩放**；点击某个地点会**飞行放大**并弹出「查看该地作品」。贴图内嵌为 data（`data/earth.js`），file:// 打开也能显示。

## 网站内管理（版头 / 增减照片）

地区画廊右侧有「**管理**」开关，打开后每张照片上会出现两个按钮：

- **版头**：把这张设为该地区的版头大图（自动记住）
- **隐藏 / 显示**：把那照片从画廊里隐藏（出现“已隐藏”区，可随时点“显示”恢复）

这些设置保存在浏览器本地（localStorage），刷新不丢。注：仅在你当前浏览器生效；若要影响所有访客，需把这些改动写入 `data/portfolio-data.js`。

> 想让版头/隐藏对所有人永久生效：在地区页点「**导出设置**」，会弹出当前所有版头/隐藏的 JSON，复制发给我（或直接告诉我哪些地区/照片），我会写进数据文件。

## 新增摄影作品

1. 把图片放到对应国家的文件夹里，建议按地区再建子文件夹，例如：
   `images/photography/china/xinjiang/01.jpg`
2. 打开 `data/portfolio-data.js`，找到对应国家下的 `region`，往 `photos` 数组里【追加一项】：

```js
{ name: "新疆", en: "Xinjiang", slug: "xinjiang", description: "", photos: [
  { src: "images/photography/china/xinjiang/01.jpg", title: "晨雾", location: "赛里木湖", year: "2024" },
]},
```

每个照片可填字段：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| `src` | 图片路径（相对 index.html） | ✅ |
| `title` | 图片标题，显示在图片下方 | 可选 |
| `location` | 拍摄地点，显示在画廊底部 `Location /` | 可选 |
| `year` | 拍摄年份（如 `2023`） | 可选 |
| `date` | 完整拍摄日期（如 `2023.03.04`），优先显示在 `Date /` | 可选 |
| `camera` | 相机型号（如 `Fujifilm X-Pro2`），显示在 `Camera /` | 可选 |
| `shot` | 焦段/光圈/快门/ISO（如 `40.7mm · f/9 · 1/1000 · ISO320`） | 可选 |

> 地区挂索引（国家、地区列表）已经全部建好，只需往里加图即可。
> 地区本身也可填 `year`（如 `year: "2026"`），用于在全屏画廊顶部以 `2026 新疆` 形式展示整组年份。

## 新增视频

在 `data/portfolio-data.js` 的 `video.mix`（混剪）或 `video.narrative`（剧情剪辑）数组里【追加一项】：

```js
video: {
  mix: [
    { title: "我的旅行混剪", src: "https://www.bilibili.com/video/xxxx", poster: "images/video/posters/mix-01.jpg", year: "2024", description: "关于旅途的混剪" },
  ],
  narrative: [
    { title: "短片练习", src: "https://example.com/video.m3u8", poster: "", year: "2023", description: "剧情向短片" },
  ],
}
```

`poster` 是封面图（选填）。`src` 填入视频/播放页链接，点击会在新窗口打开。

## 建议的图片处理

为了页面加载更快，建议：

- 摄影作品宽度在 **1600–2400px** 之间，横图为主。
- 保存为 **JPEG**，质量 80 左右。
- 后缀统一使用 `.jpg`。
